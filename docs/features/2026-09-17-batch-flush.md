# Вынести flush() из цикла в batch-юзкейсах

**Статус:** 🟡 В работе (не начато) \
**Начато:** 2026-09-17 \
**Обновлено:** 2026-09-17

## Цель

`IssueInvoicesUseCase`, `SendInvoiceToAcquireUseCase::process`, `CheckInvoicesPaidUseCase` вызывают `$this->unitOfWork->flush()` на каждой итерации цикла вместо одного раза после него. При небольшом числе договоров/счетов не критично, но не масштабируется — лишние round-trip'ы к БД на каждую запись вместо одного flush на пачку. Найдено при ревью `/src` (находка №6), выделено в отдельную задачу — делать не сейчас, а позже.

## План

1. `IssueInvoicesUseCase` — перенести `flush()` из `foreach` наружу, вызывать один раз после цикла.
2. `SendInvoiceToAcquireUseCase::process` — аналогично.
3. `CheckInvoicesPaidUseCase` — аналогично.
4. Если объём вырастет настолько, что один flush на всю пачку станет проблемой (например, очень много счетов за раз) — рассмотреть flush пачками по N, а не поштучно.
5. Прогнать `vendor/bin/codecept run Unit` (и, если БД поднята, `functional`) — поведение не должно измениться, только число обращений к БД.
