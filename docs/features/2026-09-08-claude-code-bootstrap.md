> Запись восстановлена задним числом по просьбе пользователя (2026-09-17) — на момент этой работы `docs/features/` ещё не существовал, план велась только в чате. Реконструирована из истории разговора и `git log`, не велась вживую, как это теперь предписано для новых фич (см. `README.md`).

## Цель

Подготовить проект к безопасной и осмысленной работе с Claude Code: закрыть доступ к секретам (пароли/ключи/токены) до того, как они попадут в контекст ассистента, дать ассистенту актуальный контекст о проекте (`CLAUDE.md`), и заложить процесс фиксации архитектурных решений (ADR) с первого дня работы, а не когда уже накопился долг понимания «почему тут так».

## План

Реконструирован по фактическому ходу разговора:
1. Разобрать текущий `.claude/settings.json` на предмет рисков утечки секретов через `Read`/`Bash`.
2. Расширить deny-политику, обновить `.gitignore`.
3. Обсудить назначение `settings.local.json`, `.mcp.json`, MCP-серверов в целом.
4. Провести ревью `/src` (эта часть переросла в отдельные задачи — см. [`2026-09-08-person-billing-critical-bugfixes.md`](2026-09-08-person-billing-critical-bugfixes.md) и [`2026-09-09-person-billing-acl.md`](2026-09-09-person-billing-acl.md)).
5. Завести ADR-процесс: `docs/adr/README.md`, `template.md`, ADR-0001.

## Сделано

- `.claude/settings.json`: расширен `deny` — `.env*`/ключи/`.pem`/`.mcp.json` и т.п. теперь ловятся не только в корне, но и в поддиректориях; закрыты обходные пути чтения секретов через `Bash` (`cat`, `env`, `printenv`, `docker exec ... env`), которые `deny` на `Read` не перекрывает.
- `.gitignore`: добавлены `.mcp.json`, `.claude/settings.local.json`, `.claude/.DS_Store` — личные/локальные файлы, не для команды.
- Обсуждены назначение `settings.local.json` (личные оверрайды поверх общего `settings.json`, не коммитится) и `.mcp.json` (per-project конфиг MCP-серверов; не запускается неявно — требует явного `enabledMcpjsonServers` в `settings.local.json`).
- Заведён `docs/adr/`: `README.md` (когда писать/не писать ADR, статусы, формат имени файла), `template.md`, [ADR-0001](../adr/0001-claude-md-and-adr-process.md) — решение вести `CLAUDE.md` только как гид по текущему состоянию, а историю решений — отдельно в ADR.
- `CLAUDE.md` получил ссылку на ADR-процесс.
